# ESP Fleet Controller

Control and monitor a fleet of ESP32/ESP8266 devices from a central controller.

## Features
- OTA updates for fleet devices
- MQTT command & telemetry
- Web dashboard (optional)
- ...

## Hardware
- Controller: ESP32 DevKit
- Fleet devices: ESP32-C3 / NodeMCU etc.

## Installation
1. Clone repo
2. Open in Arduino IDE / PlatformIO
3. Edit `config.h` with your WiFi & MQTT details
4. Upload to board
